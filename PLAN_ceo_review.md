## HARD CONSTRAINT (user, 2026-07-17): result must land in 30 DAYS, not 10–12 months
This overrides the long-form-compound thesis. Reality: a new YouTube channel
CANNOT be ad-monetized in 30 days — YT requires 1k subs AND (4k watch-hrs/365d OR
10M Shorts views/90d). A 30-day-old channel cannot satisfy a 90/365-day window.
So the 30-day earning target MUST be OFF-YouTube revenue, not YT ad-RPM.

OFF-YOUTUBE REVENUE PATHS THAT CAN PAY IN 30 DAYS (no YT monetization needed):
  1. Affiliate / product links in description + pinned comment. Engine ALREADY
     has the slot: engine.py:492 `affiliate = "...<your-affiliate-or-link>"`
     (currently a placeholder). Point it at a real link (Amazon Associates books,
     history/educational products, course links). Pays per conversion; needs only
     views + clicks, NOT YT approval.
  2. Digital product (one-time PDF/Notion/"history facts" pack) linked in every
     video. Pure margin, no threshold, you build it once.
  3. Patreon / memberships — needs followers but no YT monetization.
  4. Sponsors — unreliable by day 30; ignore for the gate.
The 30-day metric is NOT watch-hours. It is: (views x click_rate x conversion_x
payout) > 0, repeatedly. The engine's job in 30 days = pull enough views that
SOME clicks convert. Everything else (YT ads) is a month-4+ bonus.

REVISED GO/NO-GO (30-day horizon):
  Wedge-quality gate (retention): Short clears ~5k views@7d AND >40% avg view
    duration => wedge is viable; keep producing. (unchanged)
  30-day EARNING gate: >=1 tracked conversion (affiliate click->sale OR product

  If zero conversions by day 30 despite decent views => the link/offer is wrong

  Long-form (wedge B) is STILL valuable but now justified as a click-driver to the
